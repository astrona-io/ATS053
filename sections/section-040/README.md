# Policy Rule Structure

This section covers policy Rule Structure. It develops selectors, Peers, Ports And Application Rules through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Read endpointSelector separately from peer selectors.
- Explain endpoint, entity, CIDR and FQDN peer mechanisms.
- Combine transport and Layer 7 constraints correctly.
- Account for namespace scope, deny rules and proxy prerequisites.
