# Summary

Cilium rule structure separates the selected subject from its permitted or denied peers. Ports and application rules narrow supported communication relationships under the active implementation.

Endpoint, entity, address and FQDN mechanisms represent different kinds of peers. Namespace scope and proxy prerequisites affect the result, so a valid-looking declaration requires precise interpretation and realized-state evidence before its security intent is considered satisfied.
