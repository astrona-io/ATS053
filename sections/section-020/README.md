# Understand Cilium's Identity-based Network Security Model

This section covers understand Cilium's Identity-based Network Security Model. It develops security Identities, Labels And Address Independence through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Explain why workload labels can outlive individual Pod addresses.
- Distinguish numeric security identity from API credential identity.
- Interpret reserved identities and selector scope.
- Evaluate label integrity and identity propagation limits.
