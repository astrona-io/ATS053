# Policy Enforcement Modes

This section covers policy Enforcement Modes. It develops default, Always And Never Policy Enforcement through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Compare default, always and never agent policy modes.
- Explain direction-specific default-deny transitions.
- Interpret enableDefaultDeny and Layer 7 exceptions.
- Assess rollout dependencies before changing enforcement.
