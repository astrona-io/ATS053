# Summary

Policy enforcement mode determines how endpoints enter enforcement, while matching rules determine allowed relationships. Default mode normally transitions selected directions into default deny, always enforces across endpoints, and never disables the enforcement described by that mode.

Per-policy default-deny controls have documented limits, especially for Layer 7. Changes need dependency and endpoint review so protection and required DNS, health and management traffic remain coherent.
